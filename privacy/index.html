요즘것들연구소

개인정보처리방침

최종 업데이트: 2026년 9월

요즘것들연구소(이하 "서비스")는 뉴스 기반 콘텐츠(카드뉴스·짧은 영상)를 자동으로 제작하고, 이를 서비스 운영자가 소유한 Instagram, Threads, YouTube 계정에 게시하는 콘텐츠 큐레이션 서비스입니다. 본 방침은 서비스가 이 과정에서 어떤 정보를 어떻게 다루는지 설명합니다.

1. 서비스가 실제로 사용하는 기능

  • YouTube OAuth (Google API) — 제작된 짧은 영상 콘텐츠를 서비스 운영자 소유의 YouTube 채널에 업로드하기 위해 사용합니다.
  • Instagram API / Threads API (Meta Graph API) — 제작된 카드뉴스·영상 콘텐츠를 서비스 운영자 소유의 Instagram, Threads 계정에 게시하기 위해 사용합니다.
  • 자동 콘텐츠 제작 및 예약 게시 — 공개된 뉴스 기사를 기반으로 카드뉴스·짧은 영상을 자동 제작하고, 일정 간격을 두고 위 계정에 순차적으로 게시합니다.

2. OAuth 인증정보의 사용 목적

서비스가 요청하는 OAuth 권한(YouTube 업로드 권한, Instagram/Threads 콘텐츠 게시 권한)은 오직 서비스 운영자 본인 소유 계정에 콘텐츠를 게시하는 용도로만 사용됩니다. 이 인증정보로 다른 사용자의 계정에 접근하거나, 계정 소유자의 개인 정보(연락처, 팔로워 목록, 비공개 게시물 등)를 조회·수집하지 않습니다.

3. 수집·처리하는 정보

서비스는 일반 방문자로부터 이름, 이메일, 전화번호 등 개인 식별 정보를 별도로 수집하지 않습니다. 처리되는 정보는 다음으로 한정됩니다.

  • 공개된 뉴스 기사 제목·본문 (콘텐츠 제작 재료)
  • 제휴 상품 정보(상품명, 가격, 이미지, 제휴 링크) — 쿠팡 파트너스, 토스, 알리익스프레스, 애드픽 등 제휴 네트워크로부터 받은 공개 상품 데이터
  • 서비스 운영에 필요한 OAuth 접근 토큰(2번 항목 참고)
  • 웹사이트 방문 통계(Google Analytics) — 방문자를 개인 식별하지 않는 일반적인 트래픽 통계

4. 보관 및 삭제

OAuth 접근 토큰은 자동 게시 기능을 운영하는 데 필요한 기간 동안만 서버/로컬 환경에 안전하게 보관되며, 제3자와 공유되지 않습니다. 서비스 운영자는 언제든지 Google 계정 설정 또는 Meta 계정 설정에서 이 서비스의 접근 권한을 직접 취소(revoke)할 수 있으며, 취소 시 해당 토큰은 더 이상 사용되지 않고 폐기됩니다.

5. 제3자 API 사용

  • Google (YouTube Data API)
  • Meta (Instagram Graph API, Threads API)
  • 제휴 마케팅 네트워크: 쿠팡 파트너스, 토스, 알리익스프레스, 애드픽

각 제3자 서비스의 데이터 처리는 해당 서비스 자체의 개인정보처리방침을 따릅니다.

6. Google API 서비스 사용자 데이터 정책 준수

요즘것들연구소의 Google API에서 얻은 정보 사용 및 다른 앱으로의 정보 전송은 제한된 사용(Limited Use) 요건을 포함한 Google API 서비스 사용자 데이터 정책을 준수합니다.
