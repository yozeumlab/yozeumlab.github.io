관리자 인증

이 페이지는 GitHub 저장소(yozeumlab-hub)에 직접 접속해서 상품/배너 데이터를 수정합니다. 개인 액세스 토큰(PAT)이 필요하며, 이 브라우저에만 저장되고 외부로 전송되지 않습니다.

토큰이 없다면:
1. github.com 로그인 → Settings → Developer settings → Fine-grained tokens
2. Repository access를 yozeumlab-hub만 선택
3. Permissions에서 Contents: Read and write 부여
4. 생성된 토큰을 위 입력창에 붙여넣기
